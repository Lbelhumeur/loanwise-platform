# LoanWise Platform

The LoanWise Method platform modernization project.

## Development
Node.js 22+, npm 10+, Terraform 1.9+.

```bash
npm install
npm run validate
npm run dev
```

## Structure
- `frontend/` React applications
- `backend/` Lambda services
- `packages/` shared TypeScript/domain packages
- `infrastructure/` Terraform
- `content/` tenant-aware course content
- `docs/` engineering documentation
