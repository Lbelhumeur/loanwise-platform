# LW-0003.6 — Repository Cleanup & Canonicalization

## Purpose

Normalize the LoanWise repository before AWS infrastructure work.

## Rules

- The Git repository root is the application root.
- Work-item numbers are Git/work-tracking identifiers, not repository folders.
- Terraform belongs under `infrastructure/`.
- ZIP backups and generated artifacts do not belong in the application repository.
- Terraform state, credentials, environment files, and build output are ignored.
- The original LW-0001 Git commit remains part of history and is not rewritten.

## Result

After this cleanup, the repository is ready for LW-0004 AWS Foundation.
