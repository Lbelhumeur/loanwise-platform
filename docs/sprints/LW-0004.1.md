# LW-0004.1 --- AWS Account & Environment Foundation

## Status

**Complete**

## Objective

Establish the AWS account and environment foundation for LoanWise before
deploying application infrastructure.

## Approved Decisions

- Two functional environments: DEV/POC and PROD.
- DEV/POC uses the existing AWS account.
- PROD uses a dedicated AWS account.
- DEV contains synthetic data only.
- PROD contains real customer data.
- DEV is production-representative and fully rebuildable.
- Production infrastructure is reproducible, but production data is
  protected.
- Human identities, application identities, and infrastructure roles
  remain separate.
- Terraform is authoritative for infrastructure.
- Production security is stronger than DEV where appropriate.
- Production DR tests use protected copies/recovery sources rather
  than casually destroying authoritative production data.

## 4.1 Implementation Validation

The AWS account and environment foundation was validated through the DEV
AWS account and Terraform workflow.

- AWS IAM Identity Center administrative access was established for DEV.
- DEV account access was verified through AWS STS.
- Terraform bootstrap/state initialization succeeded.
- Terraform bootstrap configuration validation succeeded.
- The DEV Terraform state bucket was created and its Terraform outputs
  were verified.
- DEV remote backend initialization succeeded using the approved backend
  configuration.
- No production infrastructure or production data was accessed or modified.
- Environment account boundaries are enforced by the AWS provider
  llowed_account_ids configuration.
- Account IDs and credentials remain outside source control.
