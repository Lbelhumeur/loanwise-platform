# LW-0004.1 --- AWS Account & Environment Foundation

## Status

**Approved for implementation**

## Objective

Establish the AWS account and environment foundation for LoanWise before
deploying application infrastructure.

## Approved Decisions

- Two functional environments: DEV/POC and PROD.
- DEV/POC uses the existing AWS account.
- PROD uses a dedicated AWS account.
- DEV contains synthetic data only.
- PROD contains real customer data.
- DEV is production-representative and fully rebuildable.
- Production infrastructure is reproducible, but production data is
  protected.
- Human identities, application identities, and infrastructure roles
  remain separate.
- Terraform is authoritative for infrastructure.
- Production security is stronger than DEV where appropriate.
- Production DR tests use protected copies/recovery sources rather
  than casually destroying authoritative production data.
