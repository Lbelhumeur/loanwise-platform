# LW-0003.6 Reconciliation Guide

This is intentionally an incremental cleanup package.

## Before applying

Make a Git commit or create a Git branch from your current working tree.

## Required repository cleanup

1. Keep the repository root as the application root.
2. Preserve `infrastructure/environments/...` from the Terraform foundation.
3. If Terraform exists at root-level `environments/`, `bootstrap/`, or `modules/`,
   reconcile those files into `infrastructure/` and remove the duplicate root
   directories after verifying their contents.
4. Do not commit ZIP backup files.
5. Keep the original `.git` directory and Git history intact.
6. Preserve the existing `tenants.ts` until its relationship to
   `packages/domain/src/tenant.ts` is reviewed. Do not delete it automatically.
7. Run the repository validation script after cleanup.

## Do not do

- Do not reset Git history.
- Do not delete `.git`.
- Do not extract this package into an `LW-0003.6` directory.
- Do not run `terraform apply` yet.
