# LW-0004.3 - DEV Application and Delivery Foundation

## Status

**Approved for implementation**

## Objective

Establish the DEV application infrastructure and CI/CD delivery foundation
while preserving the security and environment boundaries established by
LW-0004.1 and LW-0004.2.

## Acceptance Criteria

LW-0004.3 can be closed when:

- CI is operational.
- DEV deployment is operational.
- DEV destroy/rebuild is operational.
- DEV application infrastructure is Terraform-managed.
- Application identity is separated from AWS administration.
- Application logging and monitoring are established.
- DEV deployment validation succeeds.
- DEV destroy/rebuild validation succeeds.
- No PROD infrastructure or customer data is introduced.

## Delivery Foundation Validation

- GitHub Actions OIDC authentication to the DEV deployment role succeeded.
- The deployment role successfully assumed the separate DEV Terraform service role.
- The DEV workflow initialized its remote Terraform backend from approved
  GitHub environment configuration without using an ignored local file.
- Terraform format and validation passed in GitHub Actions.
- Terraform plan and apply completed successfully with no infrastructure drift.
- The validated workflow targets only the DEV account and has no PROD actions.

## Out of Scope

- Production deployment.
- Production customer data.
- Production DNS cutover.
- Final production WAF deployment.
- Final production backup/DR implementation.
- Full production approval workflow.
