# LoanWise Project Charter

## Mission

Preserve and modernize the original LoanWise platform while respecting the creator's intellectual property, branding, educational content, and intent.

## Principles

1. Respect the original work.
2. Security by design.
3. Documentation equals code.
4. Infrastructure as Code.
5. Prefer simple, maintainable solutions.
6. Keep the platform portable between AWS accounts.
7. Design tenant-awareness into the foundation without prematurely exposing multi-tenant administration.
